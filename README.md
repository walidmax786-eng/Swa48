# ৪৮টি ক্ষমতার সূত্র — পড়ার অ্যাপ

> নতুন সংস্করণ: `index.html` এখন একাই সম্পূর্ণ (সিঙ্গেল ফাইল)। এর ভেতরেই রঙ, ৪৮টি ল-এর লেখা আর বাটনের কাজ সব আছে। তাই শুধু এই একটা ফাইল ইনস্টল / আপলোড করলেও লেখা খালি দেখাবে না। আলাদা `style.css`, `data.js`, `app.js` ফাইলগুলোও সাথে রাখা আছে, তবে সেগুলো ছাড়াই চলবে।

তোমার বলা ফরম্যাটেই বানানো হয়েছে:

- **পেজের রঙ:** সাদা
- **ল ও অর্থের লাইন:** লাল
- **ব্যাখ্যা:** নীল, আলাদা ব্লকে, বড় স্পেস দিয়ে
- **উদাহরণ:** হলুদ — হলুদ কার্ডের ওপর গাঢ় হলুদ লেখা, যাতে সাদা পেজে পড়তে কষ্ট না হয়। খাঁটি হলুদ লেখা সাদার ওপর প্রায় দেখাই যায় না, তাই পড়ার সুবিধার জন্য এই ব্যবস্থা করা হয়েছে।
- প্রতিটা ল আলাদা কার্ডে: প্রথমে ইংরেজি শিরোনাম + অর্থ, তারপর বড় ফাঁকা দিয়ে ব্যাখ্যা, তারপর নিচে আলাদা করে উদাহরণ।

## অ্যাপে যা যা আছে

- একটি করে ল পড়া, আগের ল / পরের ল বাটন, কীবোর্ডে ← → দিয়েও যাওয়া যায়
- ওপরের ড্রপডাউন থেকে যেকোনো ল নম্বরে সরাসরি যাওয়া
- ☰ সব ল বাটনে পুরো তালিকা
- সার্চ: ইংরেজি শিরোনাম বা বাংলা শব্দ দিয়ে খুঁজতে পারবে
- সবগুলো একসাথে পড়ার মোড
- শেষ কোথায় পড়েছিলে, সেটা মনে রাখে — আবার খুললে সেখান থেকেই শুরু হবে
- কোনো বাইরের ফন্ট বা সার্ভারের দরকার নেই, তাই Chrome-এ third-party cookie বন্ধ থাকলেও খুলবে

## ফাইলগুলো

- `index.html` — অ্যাপের মূল পেজ
- `style.css` — রঙ ও ডিজাইন
- `app.js` — এক ল থেকে আরেক ল-এ যাওয়া, সার্চ, মনে রাখা
- `data.js` — ৪৮টি ল-এর অর্থ, ব্যাখ্যা, উদাহরণ
- `manifest.webmanifest`, `icon.svg` — হোম স্ক্রিনে যোগ করার জন্য
- `package.json`, `capacitor.config.json` — Android APK বানানোর জন্য
- `.github/workflows/` — GitHub Actions

শিরোনামগুলো বইয়ের আসল নাম অনুযায়ী দেওয়া হয়েছে। ব্যাখ্যা ও উদাহরণ এই অ্যাপের জন্য নিজের ভাষায় লেখা, বইয়ের লেখা কপি করা হয়নি।

## ১. GitHub-এ আপলোড (সবচেয়ে সহজ উপায়)

1. GitHub-এ গিয়ে নতুন Repository বানাও, নাম দাও যেমন `laws48-app`, Public রাখো।
2. এই zip-এর ভেতরের সব ফাইল ও ফোল্ডার (`.github` সহ) ওই Repository-তে আপলোড করো। GitHub ওয়েবসাইট থেকে Add file → Upload files দিয়ে করা যায়।
3. Repository-র Settings → Pages-এ যাও। Build and deployment-এর Source-এ **GitHub Actions** বেছে নাও।
4. Actions ট্যাবে গিয়ে দেখবে `Deploy to GitHub Pages` চলছে। শেষ হলে ওখানেই তোমার লিংক দেখাবে, যেমন `https://তোমার-নাম.github.io/laws48-app/`
5. ফোনের Chrome দিয়ে ওই লিংক খুলে ⋮ → Add to Home Screen করলেই অ্যাপের মতো আইকন হয়ে যাবে।

## ২. Android APK বানানো (GitHub Action দিয়ে)

1. উপরের ধাপে ফাইল আপলোড হয়ে গেলে, GitHub-এ Repository-র **Actions** ট্যাবে যাও।
2. বাম পাশ থেকে **Build Android APK** বেছে নাও, তারপর **Run workflow** চাপো।
3. কিছুক্ষণ পর কাজ শেষ হলে, ওই Run-এর নিচে **Artifacts**-এ `laws48-app-apk` পাবে। সেটা ডাউনলোড করে zip খুললে ভেতরে `app-debug.apk` থাকবে।
4. ফোনে ওই APK খুলে Install করো। প্রথমবার Unknown sources / Install unknown apps-এর অনুমতি চাইতে পারে, সেটা Allow করতে হবে, কারণ এটা Play Store-এর অ্যাপ নয়।

দ্রষ্টব্য: APK বিল্ডটা GitHub-এর সার্ভারে হয়, তাই তোমার কম্পিউটারে Android Studio লাগবে না। বিল্ডে কোনো কারণে ভুল হলে Actions-এর লগে লাল চিহ্ন দেখাবে, সেখানে কী ভুল হয়েছে লেখা থাকবে।

## ৩. কম্পিউটারে শুধু দেখতে চাইলে

zip খুলে `index.html` ফাইলটা যেকোনো ব্রাউজারে ডাবল ক্লিক করে খুললেই চলবে, ইন্টারনেট লাগবে না।
